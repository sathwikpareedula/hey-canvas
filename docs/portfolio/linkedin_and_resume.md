## LinkedIn project description

**Hey Canvas — Local-First, Course-Aware AI Academic Copilot**

I built Hey Canvas to connect the academic information scattered across Canvas LMS, assignments, calendars, and course materials with a course-aware study workspace.

The application uses **Next.js, React, TypeScript, Python, FastAPI, SQLAlchemy, and SQLite**. It synchronizes authorized Canvas records through read-only APIs, prepares supported course documents for scoped retrieval, and offers optional local LLM-generated explanations through Ollama.

I designed deterministic retrieval paths for supported structured academic questions, source-aware context handling for explanatory questions, and asynchronous streaming with cancellation controls. Engineering work also included local storage management, Windows launchers, automated tests, and GitHub Actions verification.

The public screenshots use **synthetic academic data**. The robotics assistant screenshot contains a **prewritten demo response**, not a live LLM-generated result. The optional Ollama mode was evaluated separately and has documented limitations.

## Interview talking points

**Why not use an LLM for every question?** A database is more appropriate for known assignment and deadline records. The LLM is optional for explanations; neither approach replaces checking current Canvas source data.

**What made the backend difficult?** Cancellation of a streamed response interacted with SQLAlchemy session teardown and background setup. I added lifecycle coordination and regression tests.

**How does grounding work?** Supported documents are prepared within limits, scoped to the selected course, and associated with source provenance. Missing preparation or source text must not be described as verified evidence.

**Why local inference?** Ollama offers an optional on-device inference path with cost and data-control tradeoffs. Canvas sync still uses the network; local inference does not make the entire application offline or zero-egress.

**How was it tested?** The recorded V1.2 checkpoint passed 1,083 backend and 310 frontend tests and a five-job CI run. A separate complete real-Ollama evaluation passed 16/22 cases. The synthetic demo is not a model benchmark.

## Claims to avoid

- “100% private,” “zero data egress,” “FERPA-certified,” or “guaranteed secure.”
- “Zero hallucinations,” “perfect grounding,” or “fully accurate professor instructions.”
- “The screenshot shows a real Ollama response.” It shows a prewritten synthetic response.
- Unqualified sub-millisecond cancellation, universal latency, or unverified benchmark figures.
- “Production deployed” or “available as a hosted SaaS.” This is a local-first source release.
